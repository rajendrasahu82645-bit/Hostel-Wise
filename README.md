## 📌 About The Project

**Hostel-Wise** is a web-based **Hostel Management System** designed to simplify and digitize everyday hostel management activities.

The system helps administrators manage **students, rooms, hostel allocations, and records** from a centralized platform. It reduces manual paperwork and makes hostel information easier to organize, access, and maintain.

---

## ✨ Features

- 🔐 Secure Login System
- 👨‍🎓 Student Management
- 🏢 Hostel Management
- 🛏️ Room Management
- 📋 Room Allocation
- 📊 Dashboard & Records
- 🔍 Search and Manage Information
- 💻 User-Friendly Interface
- 📱 Responsive Design

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/rajendrasahu82645-bit/Hostel-Wise.git
```

### 2. Move the Project to XAMPP

Copy the project folder into:

```text
C:\xampp\htdocs\
```

### 3. Start XAMPP

Open XAMPP Control Panel and start:

```text
Apache
MySQL
```

### 4. Setup Database

Open:

```text
http://localhost/phpmyadmin
```

Create a new database and import the provided `.sql` database file.

### 5. Run the Project

Open your browser and visit:

```text
http://localhost/Hostel-Wise/
```
